# CatSight — measured results

Every number here came from a run against the live project. Nothing is
estimated, and anything not yet measured is listed in section 8 rather than
quoted.

- **Project** `techno-crackers-catsight` · Firestore Native, us-central1 · Cloud Run, us-central1
- **Models** `gemini-3.5-flash-lite` (agents), `gemini-3.8-flash` (verification, arbiter),
  `gemini-embedding-001` at 768 dims — Vertex AI, `location=global`

## Read this before quoting a headline number

> The extraction figures (section 2) are measured on the **eight synthetic
> wordings the prompts were developed against**. The extraction prompt went
> through six revisions, each driven by a failure on this same answer key
> (section 5 lists what each one fixed). A score on the data you tuned on is an
> **upper bound, not an expectation**. A blind set written by someone outside
> the prompt work would support a general claim; it does not exist yet.

## 2. Treaty-term extraction — current pipeline (RAG-first)

Measured 2026-10-10 with Firestore vector search live. Each term group
retrieves the top 4 clauses for its treaty (equality pre-filter on
`treaty_id`, endorsement chunks always added); Gemini reads only those
clauses; every answer must cite a retrieved clause and its quote is matched
before it is accepted.

| Measure | Result |
|---|---|
| Field accuracy against the answer key | **99.5%** (185/186) |
| Governing clause retrieved | **186/186** fields |
| Citations that check out against the page | **185/186** offered (section 3) |
| Structurally valid treaties (contiguous layers, positive limits) | **8/8** |
| Time to extract all 8 wordings | **57 s** (the earlier whole-document extractor: ~25 min) |

**The scanned endorsement.** Treaty T-004's endorsement is a rasterised page
with no text layer. It replaces the 72 hours printed in the body with 168.
Gemini transcribes the page once at ingest, and the transcription is embedded
and retrieved like any clause. Citations to it are labelled *transcribed*,
never *verified*. A text-only pipeline cannot see it and gets T-004's hours
clause confidently wrong.

**Run-to-run variation.** At temperature 0, consecutive runs still differed on
one field each (exclusion and territory lists). The book of record, not the
extraction, prices the money, so a misread term is flagged for review rather
than applied.

## 5. Earlier whole-document extractor (2026-10-05, superseded)

Kept because the lessons carried into the current pipeline.

| Measure | Result |
|---|---|
| Field accuracy | 100% (186/186) after six prompt revisions on this answer key |
| Citation page accuracy, where offered | 93.8% (135/144) |
| Citation coverage | 77.4% (144/186) — one field in four had no audit trail. This gap is why the RAG-first pipeline requires every answer to cite a retrieved clause (coverage now 186/188, section 3). |

| Revision | Accuracy | What failed |
|---|---|---|
| 1 | 87.0% *(one wording)* | `limit` never defined; contradictory flood-hours instruction; exclusions returned as whole sentences |
| 2 | 58.1% | the model computed `limit = stated − retention` on 3 of 8 — caught by structural validation, which refused all three rather than emit wrong money |
| 3 | 33.9% | quota throttling (HTTP 429) on 5 of 8 — **not** an accuracy result; retries added |
| 4 | 98.4% | the endorsement field returned empty every time |
| 5 | 99.5% | a taxonomy example over-applied |
| 6 | 100.0% | — |

Four findings that generalise:

1. **An open-ended map is the one shape the model will not populate.**
   Free-form `dict` fields came back empty every run — while the model was
   correctly *applying* the endorsement it would not describe. A list of
   records and a typed object populated immediately.
2. **`response_schema` cannot express exclusive bounds.** `Field(gt=0)` emits
   `exclusiveMinimum`, which Gemini's schema rejects. The bound stays in
   Pydantic and the API gets a relaxed twin, which makes structural validation
   load-bearing rather than defensive.
3. **Quota looks exactly like inaccuracy.** An unretried 429 is
   indistinguishable from a wrong answer in a QA report. Retries cover
   429/503/500 and dropped connections; a 400 is never retried.
4. **`temperature=0` is not determinism.** Identical settings on identical
   PDFs disagreed between runs.

## 6. Retrieval margins

Cosine similarity of the operative clause against a planted decoy
("Inspection of Records"):

| Query | Operative clause | Decoy | Margin |
|---|---|---|---|
| `"loss occurrence"` | **0.778** | 0.633 | 0.145 |
| `"hours clause"` | **0.641** | 0.624 | **0.018** |

Both rank correctly, but the legal term of art discriminates eight times
better than the colloquial phrase, so the standard queries use terms of art.
